# Security and privacy scope

This repository is a portfolio demo with synthetic data.

## Deliberately excluded

- production API hosts and group identifiers;
- service-account usernames or passwords;
- access tokens and token responses;
- internal asset field identifiers;
- employee, customer or ticket data;
- production Freshservice tenant details;
- direct links to real asset records.

The original integration used platform request templates to keep external API calls inside the Freshworks runtime. Those templates and credentials are not part of this public repository.

## Reporting

Please report a security concern privately to the repository owner instead of opening a public issue containing sensitive details.
